# アスリートジムNeeDS ／ アスリートトレーナー採用LP

アスリートジムNeeDS（神戸市灘区六甲町4丁目1-15 1F）の、
アスリートトレーナー（スポーツトレーナー）募集用ランディングページ。

既存の[採用LP](https://github.com/nakatsukasa111-tech/saiyo-lp)とは**別ページとして並列**させます。

## コンセプト

> **選手の夢を、自分の成長に変えていく。**

軸は2本。そしてこの2本が循環していることが、このLPの背骨です。

```
①選手の夢・目標をサポートする  →  選手が結果を出す
              ↑                          ↓
   より高いレベルの選手を見る  ←  自分の技術が上がる ②
```

既存の採用LPが「10年続けられる働き方＝守り」を主軸にしているのに対し、
こちらは「上がっていく＝攻め」。同じ会社の2枚のLPが、別の動機の人を拾う関係です。

## デザイン方針

**白を基調に、グレーとオレンジを差す。** 暗い面はENTRYとフッターだけに絞っています。

カラーは nds-training.jp のアスリートジム用CSS変数をそのまま継承しました。

| 役割 | 値 | 本家での変数名 |
|---|---|---|
| アクセント | `#ea5b0c` | `--athlete-accent` |
| アクセント（hover） | `#f36c19` | `--athlete-btn-hover` |
| 温かいオフホワイト | `#fdf2e6` | `--athlete-bgcolor` |
| グレー | `#4d4d4d` | `--athlete-maincolor` |
| サブグレー | `#bdbebd` | `--athlete-subcolor` |
| 背景グレー | `#eeeeee` | `--bg-gray` |
| 本文 | `#333333` | body color |
| LINE緑 | `#00b901` | `.btn-line` |

- **面の設計**：白 → `#eee` → 白 → `#fdf2e6` → 白 …と交互に。ENTRYのみ `#2b2b2b`
- **本家から踏襲したパーツ**：オレンジの角バッジ（`.badge-recommend`相当）、画像とテキストを左右交互に組む特徴ブロック（`.feature__block`相当）、角丸8px・高さ64pxのCTAボタン（`.btn-cta`相当）
- **「ゴツゴツ」**：Oswald（コンデンス体）の英字、斜めのアクセントバー、極薄の斜めストライプ
- **「洗練」**：セクション余白84px・細い罫線・eyebrow・行間1.95 ＝ women-v2 / women30 の型を継承
- 写真は軽い彩度調整のみ（`saturate(.92) contrast(1.05)`）。本家が色写真なので合わせています
- 計測：GTM `GTM-P95C26ZR`（本家サイトと同じコンテナ）
- `noindex,nofollow` を設定中。公開時に外すか判断してください
